features:
  - title: Your Slack apps keep working
    details: Web API, Events API, Socket Mode, Block Kit, modals, slash commands and OAuth installs. The compatibility table is generated by running Slack's own SDKs against the server.
  - title: Agents are first-class
    details: Streamed replies, assistant status, buttons, a built-in MCP endpoint, and rate limits you set. OpenClaw's Slack plugin connects with one environment variable.
  - title: One process, one folder
    details: npx or one container. The database is SQLite, built in; back up the folder and you have backed up everything. Files can live in an S3 bucket.
  - title: Bring your history
    details: Import Slack, Mattermost and Discord exports with threads, reactions and pins; mentions still resolve.
  - title: Calls and AI, on your terms
    details: Huddles with audio, video and screen sharing through LiveKit; summaries, recaps and search answers through the model you connect, off until you do.
  - title: Nothing held back
    details: Apache-2.0, one edition. No user cap, no history limit, no telemetry.
